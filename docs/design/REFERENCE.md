设计参考以 414 dp 宽为主。实现保留深蓝、主蓝、粉色、Poppins 字体、方形圆角封面、固定迷你播放器与五栏底部导航等主要特征，适配了当前 iPhone 的安全区和视口尺寸。

导出的部分 SVG 图标资源返回 404。对应按钮使用 Cupertino / Material 图标重建，背景等高线与导航凹口使用 Flutter 绘制，因此这些细节与原始矢量可能存在轻微差异。原图已压缩为有语义名称的 JPEG。

为保持内容一致性，歌手详情显示实际点击的歌手名；专辑歌曲数显示当前演示列表的实际数量；播放时长使用真实演示音频时长。增加了收藏列表入口、搜索空状态和演示音频标识。

原始导出中的重复、静态定位代码已由公共组件和可滚动布局替换，项目不保留不能运行的导出副本。封面图片源自用户提供的设计参考，Poppins 使用 OFL 许可证，随包音频为原创合成旋律。
